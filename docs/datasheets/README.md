## What the datasheet proves about each suffix

> The BAV99 datasheet has a `215` in the middle of it, and that is **215 mA** of
> current, not the packaging code `,215`. Checking a suffix by
> text search gives it as proven with a number that speaks of something
> else — and a wrong confirmation is worse than none, because it closes the
> question.

**`3296W-1-104LF`**  
- proves: W = side-adjust package (dimensions table, 'W series'); 104 = 100 k (codes table: 104 -> 100000)
- **does NOT prove: LF is NOT lead-free — the legend says 'LF: High-end product'**

**`BAV99,215`**  
- proves: BAV99 = dual SOT23 diode (table 3, Ordering information)
- **does NOT prove: ,215 is a packaging code and is NOT in this datasheet ('Packing information removed.') — request the Nexperia packing document**

**`OPA1642AIDR`**  
- proves: A = grade; ID = SOIC-8; R = tape and reel — the three in the ordering table at the end of the datasheet
