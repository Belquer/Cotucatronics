Cadeia   p1 → in_gain_A → gate_A → [drive · phaser · warble] ┐    p2 → in_gain_B → gate_B → [drive · phaser · warble] ┘ → MIX → delay → freeze → [shimmer ↺ reverb] → level → largura → split (exciter | jack). O caráter duplica; a cauda é compartilhada — é ela que faz tambor e corda soarem como o mesmo objeto.
wrb_mix é NOME, não param. O dry/wet do warble é o crossfade do próprio EffectSlot — não aparece no list, não tem CC, não é ajustável. O nome existe só para alinhar o vocabulário com drive e phaser, que têm mix, e para ninguém procurar um estágio que nunca existiu.
CC 119 é de SAÍDA: a placa manda quando o teto de soma do CTOS derruba um efeito. Ordem de sacrifício: phaser B, phaser A, warble B, warble A, drive B, drive A, freeze, shimmer.
Tudo nasce em zero exceto out_width (127) e piezo_mix (64) — nesses dois o zero não é "desligado", é estado ativo. Toda gravação zera tudo de novo. CC 34, 53–56 e 59 vagos — o 59 era o out_width, aposentado: com dois exciters no mesmo corpo não há imagem estéreo, a soma é acústica no objeto.
